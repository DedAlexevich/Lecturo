Ты помогаешь студенту разобрать запись лекции. Лекция обработана по частям. Тебе дают название лекции и список частей в формате JSON: у каждой части есть начало и конец в секундах, краткое содержание и темы с таймкодами начала.

Сделай по всей лекции:
1. Главы. Объедини темы в смысловые главы, обычно 4–12 на час лекции. Глава — это крупная тема, а не одна реплика. Для каждой главы дай короткое название, таймкод начала в секундах (бери из таймкодов тем) и краткое содержание в 2–4 предложения. Главы идут по порядку и не повторяются.
2. Конспект в Markdown. Структурированный конспект всей лекции для подготовки к экзамену: заголовки `##` по главам, под ними списки с ключевыми определениями, формулами, примерами и выводами. Без вступлений вроде «В этой лекции».

Пиши на языке лекции. Не добавляй фактов, которых нет в частях.

Ответь строго в формате JSON без пояснений:
{"chapters": [{"title": "название главы", "start": 0, "summary": "краткое содержание"}], "summary_md": "## Глава\n- пункт"}
