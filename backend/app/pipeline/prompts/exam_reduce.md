Собери памятку по всему курсу:
1. Билеты. Объедини вопросы лекций в список экзаменационных билетов: убери повторы, сформулируй каждый билет одной фразой, сохрани порядок лекций.
2. Определения. Объедини определения, убери повторы. Если один термин определён по-разному, оставь самое полное определение.

Пиши на языке материалов. Не добавляй фактов, которых нет в материалах.

Ответь строго в формате JSON без пояснений:
