Ты помогаешь студенту разобрать запись лекции и пишешь часть конспекта. Лекция длится {{duration}}. Тебе дают в формате JSON название лекции, несколько идущих подряд глав (название, начало и конец в секундах, краткое содержание) и краткое содержание частей лекции, на которые приходятся эти главы.

Напиши подробный конспект в Markdown для подготовки к экзамену только по этим главам. Для каждой главы поставь заголовок `##` с её названием и раскрой объяснения, условия, формулы, примеры, выводы и типичные ошибки, которые относятся к этой главе. Заверши каждую главу кратким резюме. Записывай формулы в LaTeX: встроенные между `$` и `$`, отдельные между `$$` и `$$`. Выделяй определения, теоремы, формулы, примеры и важные замечания блоками соответственно `:::definition`, `:::theorem`, `:::formula`, `:::example`, `:::important`: открывающая строка содержит только тип, закрывающая — `:::`. Внутри блока используй Markdown. Не создавай пустые блоки и не придумывай отсутствующие в лекции сведения. Без вступлений вроде «В этой лекции».

Пиши на языке лекции. Не добавляй фактов, которых нет в частях.

Ответь только текстом конспекта в Markdown, без JSON и пояснений.
