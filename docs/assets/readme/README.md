# Материалы для README

Сейчас здесь заглушки. Чтобы поставить настоящие кадры, замените файл тем же именем и тем же размером, README менять не нужно. Исходники заглушек в SVG лежат в `placeholders/`.

Общие правила для скриншотов: PNG, 1280×800, светлая тема, браузер без панелей и закладок (только содержимое вкладки), данные демо-аккаунта из [docs/demo.md](../../demo.md), без личных почт и имён. Размер файла до 1 МБ, при необходимости прогнать через `pngquant` или `oxipng`.

| Файл | Размер | Что на кадре |
|---|---|---|
| `lecture.png` | 1280×800 | страница обработанной лекции: плеер, справа расшифровка с таймкодами, видны главы |
| `summary.png` | 1280×800 | конспект лекции, где есть формулы LaTeX и хотя бы два цветных блока (определение, пример или важное) |
| `quiz.png` | 1280×800 | квиз: вопрос с вариантами, один ответ выбран, видна ссылка на момент видео |
| `search.png` | 1280×800 | поиск по курсу: запрос в поле и несколько результатов из разных лекций с таймкодами |
| `mini-app.png` | 1280×800 | Telegram Mini App: скриншот телефона (около 390×844) по центру на фоне `#f4f5f7`, экран лекции или списка курсов |
| `local.png` | 1280×800 | локальный режим: идёт распознавание в браузере, виден прогресс, или готовый результат локальной обработки |
| `demo.png` | 1280×720 | обложка демо, см. ниже |
| `social-preview.png` | 1280×640 | картинка для превью ссылки на репозиторий, см. ниже |

## Демо-видео

Нужен ролик на 30–60 секунд: ссылка на лекцию, прогресс обработки, расшифровка с переходом по таймкоду, конспект с формулами, квиз, поиск. Без звука, 1280×720.

- GIF до 10 МБ: положите как `demo.gif` и в `README.md` и `README.en.md` замените `docs/assets/readme/demo.png` на `docs/assets/readme/demo.gif`.
- Видео MP4: откройте `README.md` на GitHub в режиме редактирования и перетащите файл в текст. GitHub загрузит его и вставит ссылку вида `https://github.com/user-attachments/assets/...`, она показывается как встроенный плеер. Этой ссылкой замените блок с `demo.png`.

## Оформление репозитория

Менять настройки репозитория может только владелец. Команды:

```
gh repo edit DedAlexevich/Lecturo \
  --description "Превращает видео лекций в расшифровку с таймкодами, конспект, квиз и памятку к экзамену. Open source, работает в браузере и в Telegram" \
  --homepage https://lecturo.ru \
  --add-topic lecture,transcription,speech-to-text,study,education,fastapi,react,telegram-mini-app,pgvector,rag,russian,open-source
```

То же вручную: на главной странице репозитория шестерёнка у блока About, там поля Description, Website и Topics.

Social preview: Settings → General → Social preview → Edit → Upload an image, выбрать `social-preview.png` (1280×640, до 1 МБ). Исходник в `social-preview.svg`, после правки перегенерируйте PNG тем же размером.
