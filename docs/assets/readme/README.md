# Материалы для README

Кадры сняты на lecturo.ru: страница лекции, конспект, главы и ролик по публичной ссылке на лекцию, квиз из аккаунта с подпиской. Имя преподавателя в расшифровке размыто. Чтобы обновить кадр, замените файл тем же именем и тем же размером, README менять не нужно.

Общие правила для скриншотов: PNG, 1280×800, браузер без панелей и закладок (только содержимое вкладки), без личных почт и имён. Размер файла до 1 МБ, при необходимости прогнать через `pngquant` или `oxipng`.

| Файл | Размер | Что на кадре |
|---|---|---|
| `lecture.png` | 1280×800 | страница обработанной лекции: плеер, справа расшифровка с таймкодами |
| `summary.png` | 1280×800 | конспект лекции, где есть формулы LaTeX и хотя бы два цветных блока (определение, пример или важное) |
| `quiz.png` | 1280×800 | квиз: вопрос с вариантами, один ответ выбран, видна ссылка на момент видео |
| `quiz-question.png` | 1280×800 | квиз: вопрос с вариантами до ответа |
| `chapters.png` | 1280×800 | вкладка «Главы»: главы с таймкодами и кратким содержанием |
| `demo.gif` | 960×540 | демо-ролик, см. ниже |
| `social-preview.png` | 1280×640 | картинка для превью ссылки на репозиторий, см. ниже |

## Демо-видео

`demo.gif`: ролик около 40 секунд, 960×540, 10 кадров в секунду, до 10 МБ. Снят в браузере по публичной ссылке на лекцию: конспект с формулами, главы, расшифровка.

Чтобы показать ролик встроенным плеером, откройте `README.md` на GitHub в режиме редактирования и перетащите в текст MP4. GitHub вставит ссылку вида `https://github.com/user-attachments/assets/...`, ею можно заменить блок с `demo.gif`.

## Оформление репозитория

Менять настройки репозитория может только владелец. Команды:

```
gh repo edit DedAlexevich/Lecturo \
  --description "Превращает видео лекций в расшифровку с таймкодами, конспект, квиз и памятку к экзамену. Open source, работает в браузере и в Telegram" \
  --homepage https://lecturo.ru \
  --add-topic lecture,transcription,speech-to-text,study,education,fastapi,react,telegram-mini-app,pgvector,rag,russian,open-source
```

То же вручную: на главной странице репозитория шестерёнка у блока About, там поля Description, Website и Topics.

Social preview: Settings → General → Social preview → Edit → Upload an image, выбрать `social-preview.png` (1280×640, до 1 МБ). Исходник в `social-preview.svg`, после правки перегенерируйте PNG тем же размером.
