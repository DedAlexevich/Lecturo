# Демо для жюри

Сценарий из раздела 14 ТЗ: что нажимать, что должно получиться и что подготовить заранее. Шаги, которые пока не работают в main, помечены номером issue, от которого они зависят.

Сервер для демо поднимается в #62, автодеплой — в #63. Пока их нет, сценарий можно прогнать только локально (`docker compose up --build`, сайт на http://localhost), и то не целиком: Telegram и вебхуки ЮKassa без публичного HTTPS не работают.

- [ ] Второй аккаунт «Демо с подпиской» с активной подпиской и той же готовой лекцией 1, на нём показываем квиз (шаг 4).

## Лекции

Нужны 2–3 лекции на русском по 5–10 минут, с открытой лицензией, на VK Видео и Rutube.

На VK Видео и Rutube нет поля лицензии и фильтра по ней, поиск по описаниям роликов не нашёл коротких лекций с явно указанной Creative Commons. Брать чужие ролики «на всякий случай» не стоит: показ на демо — публичное использование. Поэтому предлагаю два варианта, оба с чистой лицензией.

### Вариант 1, основной: свои записи

Записываем 2–3 лекции по 5–7 минут сами (экран со слайдами и голос), выкладываем с аккаунта команды на VK Видео и на Rutube, в описании пишем «Лицензия CC BY 4.0». Так ссылки точно не пропадут, и мы заранее знаем, о чём говорится в лекции, поэтому подготовить вопрос для поиска и квиза проще.

Темы, удобные для поиска и квиза (понятные термины, есть что спросить):

| № | Тема | Вопрос для поиска на шаге 3 |
|---|---|---|
| 1 | Двоичный поиск | «где объясняли сложность двоичного поиска» |
| 2 | Хеш-таблицы и коллизии | «где говорили про коллизии» |
| 3 | Сортировка слиянием | «где объясняли, почему n log n» |

Все три кладём в курс «Демо», тогда поиск по курсу (шаг 3) находит фрагмент в другой лекции, а не в той, что открыта.

Ссылки после публикации:

| № | VK Видео | Rutube | Длительность | Лицензия |
|---|---|---|---|---|
| 1 | будет после записи | будет после записи | | CC BY 4.0 |
| 2 | будет после записи | будет после записи | | CC BY 4.0 |
| 3 | будет после записи | будет после записи | | CC BY 4.0 |

### Вариант 2, запасной: фрагменты лекций НГУ под CC BY 3.0

На Wikimedia Commons выложены записи лекций кафедры теоретической физики НГУ под лицензией CC BY 3.0. Сами лекции идут по 1,5 часа, но CC BY разрешает вырезать фрагмент и выкладывать его повторно с указанием автора. Вырезаем 5–10 минут, выкладываем на VK Видео и Rutube, в описании указываем автора, ссылку на оригинал и лицензию.

|---|---|---|---|

Автор во всех трёх — канал «Лекции по теоретической физике» (НГУ), оригиналы на YouTube. Минус варианта: темы сложные, для демо квиз и поиск по ним выглядят хуже, чем по своим записям.

### Проверка ссылок перед демо

- Ссылка открывается в браузере без входа и без возрастного ограничения.
- Ролик публичный, а не «доступ по ссылке» с ограничением по региону.
- Добавление по ссылке доходит до готового конспекта (после #21).

## Тестовый аккаунт

Пароли в репозиторий не пишем. Аккаунт создаётся на демо-сервере так:

1. Открыть `https://<домен>/register`.
2. Почта — общий ящик команды, пароль — из общего хранилища паролей команды.
3. Привязать Telegram того, кто будет показывать демо: «Кабинет» → способы входа (после #7 и #50). Пока этого нет, для шага 1 используется отдельный аккаунт, созданный входом через Telegram.
4. Создать курс «Демо», добавить в него две лекции и дождаться обработки.

Подтверждение почты пока не обязательно для входа (#4 не сделан).

Для шага 4 так же заводим второй аккаунт, «Демо с подпиской». В «Кабинете» выбрать «Подписка на 30 дней», оплатить тестовой картой 5555 5555 5555 4444 и добавить в него лекцию 1. Квиз доступен только с подпиской, пакет часов подписку не даёт, поэтому на основном аккаунте после шага 5 квиз не откроется.

Для шага 5 у аккаунта должен почти закончиться недельный лимит. Бесплатный лимит — `FREE_WEEKLY_SECONDS` (2 часа). Перед демо на сервере удобнее временно уменьшить его, например до 900 секунд, чтобы третья лекция не помещалась в остаток. После демо вернуть значение.

## Тестовые карты ЮKassa

Работают только в тестовом магазине, настоящие карты там не принимаются. Срок действия — любой в будущем, CVC — любой, код 3-D Secure — любой. Источник: https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing

Успешная оплата:

| Карта | Номер | 3-D Secure |
|---|---|---|
| Mastercard | 5555 5555 5555 4477 | да |
| Мир | 2200 0000 0000 0004 | да |
| Mastercard | 5555 5555 5555 4444 | нет |
| Visa | 4111 1111 1111 1111 | нет |
| Мир | 2202 4743 0132 2987 | нет |

Для демо берём 5555 5555 5555 4444: без 3-D Secure на один экран меньше.

Отказ, если нужно показать ошибку оплаты:

| Причина | Mastercard | Мир |
|---|---|---|
| недостаточно средств (`insufficient_funds`) | 5555 5555 5555 4600 | 2200 0000 0000 0053 |
| общий отказ (`general_decline`) | 5555 5555 5555 4527 | 2202 2022 1231 2379 |

## Сценарий

Время на весь показ — около 5 минут. Перед началом открыть сайт на ноутбуке и бота на телефоне.

### 1. Вход через Telegram в Mini App

Зависит от #65 (вход по initData, PR #107) и #66 (адаптация фронта под Mini App). Бот и кнопка Mini App уже есть (#67).

1. В Telegram открыть бота, нажать `/start`.
2. Нажать кнопку открытия Mini App.

Должно получиться: Mini App открывается сразу в кабинете без формы входа, цвета под тему Telegram, работает кнопка «назад».

Запасной путь: на сайте `/login` → кнопка Telegram Login Widget (уже в main).

### 2. Ссылка на лекцию, прогресс, конспект и главы, таймкоды

Зависит от #41 (форма добавления), #21 (ссылки через yt-dlp, `POST /api/v1/lectures/link`), #24, #25, #27 (аудио, распознавание, главы и конспект), #32 (статус обработки), #42 и #43 (страница лекции), #78 (встроенный плеер VK Видео и Rutube). Главная со списком лекций — #40.

1. На главной нажать «Добавить лекцию», вставить ссылку на лекцию 3 (VK Видео или Rutube), выбрать курс «Демо».
2. Открывается страница лекции со статусом обработки по шагам.

Должно получиться: шаги идут по очереди с прогрессом (аудио → распознавание → главы и конспект → поиск), через 1–3 минуты появляются расшифровка, главы и конспект. Плеер — встроенный плеер VK Видео или Rutube.

3. Нажать на фразу в расшифровке или на главу.

Должно получиться: видео перематывается на этот момент.

Пока обрабатывается лекция 3, можно показывать заранее готовую лекцию 1.

### 3. Поиск по курсу

Зависит от #29 (фрагменты для поиска), #30 (гибридный поиск, `GET /api/v1/search`), #45 (экран поиска).

1. Открыть курс «Демо».
2. В поиске по курсу ввести вопрос из таблицы лекций, например «где говорили про коллизии».

Должно получиться: первым результатом идёт фрагмент из нужной лекции с таймкодом, по клику открывается лекция на этом моменте.

### 4. Квиз со ссылкой на момент видео

Зависит от #34 (генерация квиза, `POST /api/v1/lectures/{id}/quiz`) и #58 (экран квиза). Сейчас эндпоинты квиза в main отвечают «не готово». Квиз доступен только с подпиской: проверка подписки из #16 уже есть, а на эндпоинтах квиза она включится вместе с #34. Поэтому шаг показываем на заранее подготовленном аккаунте «Демо с подпиской», а не на основном: пакет часов, купленный на шаге 5, подписку не даёт.

1. Переключиться на второе окно браузера (отдельный профиль), где заранее выполнен вход в «Демо с подпиской», и открыть лекцию 1.
2. На странице лекции нажать «Квиз».
3. Ответить на вопрос неверно.

Должно получиться: видно, что ответ неверный, и есть ссылка на таймкод, где это объясняли. По ссылке видео перематывается на этот момент.

### 5. Нехватка лимита, диалог приоритета, оплата, лимит пополнен

Зависит от #22 (проверка лимита и очередь «ожидает», сейчас `GET /api/v1/billing/waiting` и `POST /api/v1/billing/queue-plan` отвечают «не готово») и #47 (диалог приоритета). Кабинет с лимитом и оплатой уже в main (#9, #10, #11, #46). Для приёма вебхука нужен сервер с HTTPS (#62).

1. Добавить сразу две лекции, которые вместе не помещаются в остаток лимита.

Должно получиться: открывается диалог приоритета с длительностью каждой лекции и остатком лимита. Выбрать одну лекцию для обработки сейчас, вторая получает статус «ожидает» и три варианта: дождаться сброса, купить пакет, обработать на устройстве.

2. Выбрать «купить пакет». Открывается «Кабинет» (`/account`).
3. Выбрать «Пакет 5 ч», отметить «Принимаю условия публичной оферты», нажать «Оплатить 199 ₽».
4. На странице ЮKassa ввести карту 5555 5555 5555 4444, любой будущий срок и любой CVC, оплатить.

Должно получиться: возврат в кабинет, короткое «Проверяем оплату», затем в блоке «Пакеты» появляются 5 часов, в истории платежей — оплаченный платёж. Лекция со статусом «ожидает» уходит в обработку (после #22).

### 6. Та же лекция локально в браузере без интернета

Зависит от #54 (экран локальной обработки), #52 (извлечение аудио на клиенте), #57 (PWA и офлайн), #55 (хранение результата без аккаунта). Whisper в браузере уже в main (#51), но маршрута для него в `frontend/src/app/routes.tsx` пока нет.

1. На ноутбуке открыть экран локальной обработки, пока интернет есть, чтобы приложение и модель были в кеше.
2. Выключить Wi-Fi.
3. Выбрать файл лекции 1, нажать «Обработать на устройстве».

Должно получиться: расшифровка появляется по ходу обработки, в сети нет запросов, результат можно открыть и экспортировать. После включения интернета результат можно отправить в аккаунт (#56), и лекция появится в кабинете с меткой «обработано на устройстве».

## Чек-лист прогона после крупных мержей

Прогоняем на сервере после каждого мержа, который затрагивает шаги демо. Всё, что не прошло, оформляем багом на зону шага (см. CLAUDE.md, раздел «Проблемы вне моей задачи»).

| Проверка | Как | Зона при ошибке |
|---|---|---|
| Сайт и API живы | `https://<домен>/api/v1/health` отвечает 200, главная открывается | bot-devops |
| Вход по почте | `/login` с тестовым аккаунтом, попадаем на главную | backend, local |
| Вход через Telegram на сайте | кнопка Telegram Login Widget на `/login` | backend |
| Mini App | шаг 1 | bot-devops |
| Ссылка VK Видео | шаг 2 со ссылкой на VK Видео, лекция доходит до конспекта | pipeline |
| Ссылка Rutube | шаг 2 со ссылкой на Rutube | pipeline |
| Таймкоды и плеер | клик по фразе и по главе перематывает видео | frontend |
| Поиск по курсу | шаг 3, нужный фрагмент в первой тройке | backend, pipeline |
| Квиз | шаг 4 на аккаунте «Демо с подпиской» | pipeline, local |
| Лимит в кабинете | `/account` показывает остаток и время сброса | frontend, backend |
| Диалог приоритета | шаг 5, пункт 1 | frontend, backend |
| Оплата тестовой картой | шаг 5, пункты 2–4, пакет начислен | backend |
| Отказ оплаты | карта 5555 5555 5555 4600, в кабинете понятная ошибка, ничего не начислено | backend, frontend |
| Локальный режим офлайн | шаг 6 с выключенным интернетом | local |
| Экспорт | PDF, SRT и VTT у готовой лекции скачиваются | backend, bot-devops |

После прогона вернуть тестовому аккаунту исходное состояние: удалить лекцию, добавленную на шаге 2, и пополнить лимит, если он ушёл в ноль.
