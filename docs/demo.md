# Демо для жюри

Сценарий из раздела 14 ТЗ: что подготовить, что нажимать и что должно получиться. Все шаги уже есть в main. Не хватает только сервера: первый деплой с доменом и HTTPS делается в #62, автодеплой в #63. Без публичного HTTPS не работают Mini App, вход через Telegram и вебхуки ЮKassa, поэтому целиком сценарий проходит только на сервере.

## Лекции

Нужны 2–3 лекции на русском по 5–10 минут, с открытой лицензией, на VK Видео и Rutube.

### Откуда берём

На VK Видео и Rutube нет поля лицензии, и коротких лекций с явно указанной Creative Commons там не нашлось. Чужие ролики без явной лицензии не берём: показ на демо — публичное использование. Поэтому исходники берём с Wikimedia Commons, где лицензия указана у каждого файла, и выкладываем их на VK Видео и Rutube с аккаунта команды. CC BY разрешает распространять и вырезать фрагменты, если указать автора, источник, лицензию и что изменено. Подробности поиска — в #53.

### Как выложить

1. Скачать файл со страницы Commons (кнопка «Скачать», для лекции 1 хватает версии 480p или 720p).
2. Для лекций 2 и 3 вырезать фрагмент, например `ffmpeg -ss <начало> -to <конец> -i <файл> -c copy fragment.webm`.
3. Загрузить на VK Видео и на Rutube с аккаунта команды, ролик публичный.
4. В описание вставить подпись:

```
Фрагмент лекции А. Коржиманова «В фокусе петаваттного лазера», часть 1.
Авторы: Артём Коржиманов (лекция), Fancy Studio (анимация), Krassotkin (съёмка и монтаж).
Оригинал: <ссылка на страницу Commons>.
Лицензия CC BY 4.0, https://creativecommons.org/licenses/by/4.0/deed.ru
Изменения: вырезан фрагмент <начало>–<конец>.
```

Для лекции 3 автор — канал «Лекции по теоретической физике» (НГУ), лицензия CC BY 3.0, https://creativecommons.org/licenses/by/3.0/deed.ru. Для лекции 1 строку «Изменения» не пишем, если файл не резали.

### Проверка ссылок перед демо

- Ссылка открывается в браузере без входа и без возрастного ограничения.
- Ролик публичный, а не «доступ по ссылке», без ограничения по региону.
- На сервере ссылка через «Добавить лекцию» доходит до готового конспекта, а плеер на странице лекции встроенный (VK Видео или Rutube).

Прямую ссылку на файл Commons в «Добавить лекцию» не вставляем: Wikimedia отвечает на скачивание 429 Too many requests (проверено на локальном стенде). Сам файл при этом загружается через «Добавить лекцию» → файл без проблем.

## Тестовый аккаунт

Пароли в репозиторий не пишем. Аккаунты создаются на демо-сервере так:

1. Открыть `https://<домен>/register`.
2. Почта — общий ящик команды, пароль — из общего хранилища паролей команды. Адреса на служебных доменах (`.test`, `.invalid`, `.local`) форма не принимает.
3. Отметить согласие с офертой и на обработку персональных данных.
4. «Кабинет» → способы входа → привязать Telegram того, кто показывает демо. Тогда на шаге 1 Mini App открывает этот же аккаунт.
5. При первом добавлении лекции подтвердить согласие на передачу данных провайдерам распознавания и LLM, без него лекция не добавляется.
6. Создать курс «Демо», добавить в него лекции 1 и 2 и дождаться обработки.

Второй аккаунт «Демо с подпиской» заводится так же, на другую почту. В «Кабинете» выбрать «Подписка на 30 дней», оплатить тестовой картой 5555 5555 5555 4444, добавить лекцию 1. Квиз доступен только с подпиской, пакет часов подписку не даёт, поэтому квиз показываем на этом аккаунте.

Для шага 5 у основного аккаунта должен почти закончиться недельный лимит. Бесплатный лимит — `FREE_WEEKLY_SECONDS` (2 часа). Перед демо на сервере его временно уменьшают, после демо возвращают значение.

Лимит списывается по длительности лекции, округлённой вверх до секунды. Длительности: лекция 1 — 486 с, лекции 2 и 3 — по 480 с (фрагменты режем ровно по 8:00), части 2 и 3 для шага 5 — по 761 с. Лимит считаем так: лекции 1, 2 и 3 плюс остаток, который меньше одной части для шага 5:

```
486 + 480 + 480 + 604 = 2050
FREE_WEEKLY_SECONDS=2050
```

Тогда до демо, после обработки лекций 1 и 2, остаётся 1084 с: лекция 3 на шаге 2 помещается. После шага 2 остаётся 604 с (10 мин), и на шаге 5 обе части не помещаются. Если фрагменты получились другой длины, пересчитать по той же формуле: остаток после шага 2 должен быть меньше 761 с.

## Тестовые карты ЮKassa

Работают только в тестовом магазине, настоящие карты там не принимаются. Срок действия — любой в будущем, CVC — любой, код 3-D Secure — любой. Источник: https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing (сверено 27.10.2026).

Успешная оплата:

| Карта | Номер | 3-D Secure |
|---|---|---|
| Mastercard | 5555 5555 5555 4477 | да |
| Visa | 4793 1281 6164 4804 | да |
| Мир | 2200 0000 0000 0004 | да |
| Mastercard | 5555 5555 5555 4444 | нет |
| Visa | 4111 1111 1111 1111 | нет |
| Мир | 2202 4743 0132 2987 | нет |

Для демо берём 5555 5555 5555 4444: без 3-D Secure на один экран меньше.

Отказ, если нужно показать ошибку оплаты:

| Причина | Mastercard | Мир |
|---|---|---|
| недостаточно средств (`insufficient_funds`) | 5555 5555 5555 4600 | 2200 0000 0000 0053 |
| общий отказ (`general_decline`) | 5555 5555 5555 4527 | 2202 2022 1231 2379 |

## Сценарий

Время на весь показ — около 5 минут. Перед началом открыть сайт на ноутбуке и бота на телефоне.

### 1. Вход через Telegram в Mini App

1. В Telegram открыть бота, нажать `/start`.
2. Нажать кнопку «Открыть Lecturo».

Должно получиться: Mini App открывается без формы входа сразу на главной `/` со списком лекций и курсов, цвета под тему Telegram, работает кнопка «назад».

Запасной путь: на сайте `/login` → кнопка входа через Telegram.

### 2. Ссылка на лекцию, прогресс, конспект и главы, таймкоды

1. На главной нажать «Добавить лекцию», вставить ссылку на лекцию 3 (VK Видео или Rutube), выбрать курс «Демо».
2. Открывается страница лекции со статусом обработки по шагам.

Должно получиться: шаги идут по очереди с прогрессом (аудио → распознавание → главы и конспект → поиск), через 1–3 минуты появляются расшифровка, главы и конспект. Плеер — встроенный плеер VK Видео или Rutube.

3. Нажать на фразу в расшифровке или на главу.

Должно получиться: видео перематывается на этот момент.

Пока обрабатывается лекция 3, можно показывать заранее готовую лекцию 1. Лимит на это есть: до шага 2 остаётся 1084 с, лекция 3 занимает 480 с, после неё остаётся 604 с.

### 3. Поиск по курсу

1. Открыть курс «Демо».
2. В поиске по курсу ввести вопрос по лекции 2, подготовленный заранее.

Должно получиться: первым результатом идёт фрагмент из нужной лекции с таймкодом, по клику открывается лекция на этом моменте.

### 4. Квиз со ссылкой на момент видео

1. Переключиться на второе окно браузера (отдельный профиль), где выполнен вход в «Демо с подпиской», и открыть лекцию 1.
2. На странице лекции нажать «Квиз».
3. Ответить на вопрос неверно.

Должно получиться: видно, что ответ неверный, и есть ссылка на таймкод, где это объясняли. По ссылке видео перематывается на этот момент.

### 5. Нехватка лимита, диалог приоритета, оплата, лимит пополнен

1. На основном аккаунте через «Добавить лекцию» добавить ссылкой часть 2, затем часть 3 (по 12:41). После шага 2 осталось 10 минут лимита, ни одна часть не помещается.

Должно получиться: обе части получают статус «ожидает», открывается диалог «Не хватает лимита» с длительностью каждой части, остатком 10 мин и тремя вариантами: дождаться обновления лимита, купить пакет часов, обработать на устройстве.

2. Выбрать «купить пакет». Открывается «Кабинет» (`/account`).
3. Выбрать «Пакет 5 ч», отметить «Принимаю условия публичной оферты», нажать «Оплатить 199 ₽».
4. На странице ЮKassa ввести карту 5555 5555 5555 4444, любой будущий срок и любой CVC, оплатить.

Должно получиться: возврат в кабинет, короткое «Проверяем оплату», затем в блоке «Пакеты» появляются 5 часов, в истории платежей — оплаченный платёж.

5. Снова открыть диалог приоритета, отметить обе части.

Должно получиться: обе части уходят в обработку. Сначала списываются 604 с недельного остатка, затем пакет: в «Пакетах» остаётся около 4 ч 45 мин. Сами по себе после оплаты лекции не стартуют, их выбирают в диалоге.

### 6. Та же лекция локально в браузере без интернета

1. На ноутбуке открыть `/local`, пока интернет есть, чтобы приложение и модель были в кеше.
2. Выключить Wi-Fi.
3. Выбрать файл лекции 1, нажать «Обработать на устройстве».

Должно получиться: расшифровка появляется по ходу обработки, в сети нет запросов, результат сохраняется в списке на устройстве и экспортируется. После включения интернета результат можно отправить в аккаунт, и лекция появится в списке с меткой «обработано на устройстве».

## Чек-лист прогона после крупных мержей
